SABC

Connect in three steps

Rabbit speaks MCP over Streamable HTTP. If your assistant supports remote MCP servers, it works.

  1. 1

    Add the URL

    Paste the endpoint into your client's MCP settings — or use a snippet below.

  2. 2

    Sign in once

    Your client opens an OAuth window. Approve it and you're done — no API key to copy.

  3. 3

    Ask something

    Try “What does the yield curve look like versus a year ago?” and watch the tool calls.

Add to ~/.cursor/mcp.json (or the project's .cursor/mcp.json):

{
  "mcpServers": {
    "rabbit": {
      "url": "https://the-macro-dashboard.com/mcp"
    }
  }
}

Run once in your terminal:

claude mcp add --transport http rabbit https://the-macro-dashboard.com/mcp

Then run /mcp inside Claude Code and choose “Authenticate” for rabbit.

In Settings → Connectors, choose “Add custom connector”, then enter:

Name: Rabbit
URL:  https://the-macro-dashboard.com/mcp

Menu names vary by plan and version. Any client with remote-MCP support follows the same pattern.

Point any Streamable-HTTP MCP client at the endpoint. To poke around first, use the MCP Inspector:

npx @modelcontextprotocol/inspector@latest
# transport: Streamable HTTP
# URL: https://the-macro-dashboard.com/mcp
Heads-up: the endpoint may change. The URL above is the current production endpoint. We plan to move Rabbit to its own domain; when that happens this page will show the new URL and the old one will keep working through a transition period.

Four ways people go down the hole. Tool names are real; the sessions are illustrative.

Questions

Is Rabbit really free?

Yes — Rabbit is free to use. You sign in with OAuth so the service can tell users apart and protect itself from abuse, but there's no card and no plan to pick.

Is it open source?

No. Rabbit is a free, hosted service and its code is closed. This website's repository contains only the static pages you're reading — no server code.

Why hosted instead of a package I install?

Because the tools lean on live official data and curated knowledge that would be painful to run yourself. One URL means no dependencies, no updates to chase, and every client gets the same catalog.

What about my privacy and my data?

Rabbit doesn't ask for brokerage credentials, doesn't place orders and doesn't execute your code. Charts and calculations are assembled in your own assistant. Like any hosted service it handles operational basics (who is signed in, which tool ran, how long it took). Don't paste secrets into prompts.

Does it give financial advice or trade for me?

No. Rabbit is research tooling: it surfaces data, methods and evidence. Decisions — and risk — stay with you.

Where does the data come from?

Official and primary sources: FRED, EIA and CFTC for macro series; SEC and BLS for public-company and labor facts; arXiv for papers. Attribution and coverage caveats are preserved in outputs.

Which assistants work with it?

Anything that supports remote MCP over Streamable HTTP with OAuth — Cursor, Claude Code, Claude's app and web, and other MCP clients.

Will the URL change?

Possibly. We intend to move to a dedicated Rabbit domain. This site will always list the current endpoint, and we'll keep the old one alive during the transition.
